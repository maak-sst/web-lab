# Kibo.ua

Навчальний проєкт з дисципліни «Веб-орієнтована розробка програмного забезпечення» (НН ІПСА, КПІ ім. Ігоря Сікорського).
Лабораторна робота №2: створення структури веб-проєкту.

Сайт для продажу готових термосумок зі складу та індивідуального пошиття через онлайн-конструктор. Ідея, кольори, шрифти та карта сайту взяті з лабораторної роботи №1.

## Структура

```
kibo/
├── index.html          головна
├── catalog.html        каталог готових сумок
├── constructor.html    онлайн-конструктор
├── materials.html      про матеріали
├── contacts.html       контакти та форма заявки
├── css/style.css
├── js/
│   ├── main.js         меню, фільтр каталогу, форми
│   └── constructor.js  розрахунок вартості
├── images/             логотип та зображення товарів (SVG)
└── README.md
```

## Запуск

Збірка не потрібна, достатньо відкрити `index.html` у браузері. Шрифти (Inter, Rubik, Fira Sans) підключаються з Google Fonts.

## Що далі

Бекенд (PHP + MySQL), кошик, особистий кабінет і англійська версія будуть у наступних роботах.
